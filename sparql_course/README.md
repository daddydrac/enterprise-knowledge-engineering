# SPARQL for enterprise ontology engineering

This revised 19-topic course uses the same published healthcare subset and Python environment as the enterprise book. Start with the parent README, then S00 in notebooks/sparql. The topic crosswalk maps all 19 original lessons to ten executable notebooks. E14 supplies an additional basic SWRL exercise; E08 teaches SHACL in practice.

OWL DL reasoning is explicit: the core uses OWLAPI and HermiT, and SPARQL queries a finite export of named class memberships. Data validation, rule extensions and graph querying remain separately testable responsibilities.
